# O LABIRINTO — felipe_luiz_lar_260909

Jogo **O LABIRINTO**: a **Ovelha 🐑** precisa pegar **TODAS as moedas 🪙** sem ser pega pelo **Lobo 🐺** (persegue) e pelos **Caçadores 🏹** (patrulham).

Jogue online: https://larandreluizinfo.github.io/felipe_luiz_lar_260909/

## Como jogar

- PC: setas ou WASD
- Celular: botões ⬆️⬇️⬅️➡️ na tela
- Objetivo: coletar todas as moedas
- Cuidado: se o Lobo ou um Caçador encostar em você, perde 1 vida (3 vidas no total)
- Botões: 🔄 Reiniciar · ⏸️ Pausar

## Arquivos

- `index.html` — página do jogo
- `style.css` — visual
- `game.js` — lógica (labirinto, BFS do Lobo, patrulha dos Caçadores, moedas, vidas, recorde)
